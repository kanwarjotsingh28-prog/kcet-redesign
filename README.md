# KCET Amritsar: Website Redesign Concept

A UI redesign concept for the homepage and key inner pages of Khalsa College of Engineering & Technology, Amritsar.

**This is an unofficial student concept project.** It is not affiliated with or endorsed by the college. All content and links come from the college's public website: https://khalsaengineering.co.in

## What's included
- Redesigned homepage with notices in the hero, simplified navigation and quick links
- Inner pages: Admission, Computer Science & Engineering, Training & Placement, Contact
- Responsive layout, keyboard focus styles, automatic light and dark mode
- Single file (`index.html`), no build step, no dependencies

## Run locally
Open `index.html` in a browser.

## Notes
- Fees, eligibility and placement figures are intentionally left to the official pages.
- Pages are switched with URL hashes (`#admission`, `#cse`, `#placement`, `#contact`).
